
To run the code successfully, a Groq API key and Azure NLU key must be created and stored in the `src` directory.
After those are generated, you can follow the steps below to run the game:

1. Launch Furhat SDK and Remote API

2. Add a user to the Furhat SDK dashboard (so that Furhat attends to the user)

3. Run the following command from the `src` directory:
```
npm run dev
```

4. Use the START/STOP/RESTART buttons in the UI to control the game
